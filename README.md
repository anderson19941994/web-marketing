# 🚀 Creative Studio | Agencia de Marketing Digital

Bienvenido al repositorio de **Creative Studio**, una plataforma web moderna, responsiva y de alto impacto visual diseñada para agencias de marketing y publicidad.

Este proyecto ha sido desarrollado por **Anderson Studio** como parte de un portafolio profesional de soluciones digitales.

---

## ✨ Características Principales

*   **Diseño UI/UX Moderno:** Interfaz limpia con gradientes dinámicos y tipografía Montserrat.
*   **Totalmente Responsivo:** Adaptado para dispositivos móviles, tablets y escritorio (Mobile First).
*   **Secciones Estratégicas:**
    *   **Inicio (Hero):** Captación de atención con mensajes claros.
    *   **Servicios Detallados:** Explicación de propuestas de valor y planes de precios.
    *   **Portafolio:** Galería de trabajos realizados con efectos de hover.
    *   **Contacto:** Formulario funcional y estético para captación de leads.
*   **Optimización de Carga:** Uso de iconos de FontAwesome y fuentes de Google Fonts vía CDN.

---

## 🛠️ Tecnologías Utilizadas

*   **HTML5:** Estructura semántica avanzada.
*   **CSS3:** Estilos modernos, Flexbox, CSS Grid y Animaciones.
*   **FontAwesome:** Iconografía profesional.
*   **Google Fonts:** Tipografía de alta calidad.

---

## 🚀 Instalación y Vista Previa

Si deseas ver el proyecto localmente, sigue estos pasos:

1.  **Clona el repositorio:**
    ```bash
    git clone [https://github.com/TU_USUARIO/creative-studio-web.git](https://github.com/TU_USUARIO/creative-studio-web.git)
    ```
2.  **Entra a la carpeta:**
    ```bash
    cd creative-studio-web
    ```
3.  **Abre el archivo `index.html`** en tu navegador favorito.
